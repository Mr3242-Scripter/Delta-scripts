## Getting started

1. Browse the [script index](Scripts/QuantumX%20Script%20list) or open the Scripts folder.
2. Select the script you want to understand.
3. Read the complete source before deciding whether to use it.
4. Check what the code does, what environment it expects, and whether it makes network requests or changes game state.

## Safety and compatibility

- Only use code you have reviewed and understand.
- Treat code downloaded from the internet as untrusted until you have inspected it.
- A raw URL only provides the text; it does not prove that the code is safe.
- Avoid relying on remote files that can be changed without notice.
- Never put passwords, private tokens, API keys, or other secrets in scripts or public files.
- Read each script's own notes because scripts may depend on a particular game or environment.
- Back up your own projects before testing unfamiliar code.
