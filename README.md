## Getting started

1. Browse the [script index](Scripts/QuantumX%20Script%20list) or open the Scripts folder.
2. Select the script you want to understand.
3. Read the source before using it. Check what services, permissions, network requests, and game changes it makes.
4. Follow the instructions provided for that specific script and make sure it is compatible with your environment.

### About loadstring

The [loadstring guide](Scripts/How%20to%20use%20loadstring) explains Roblox Studio's server-side feature, remote source loading, and the important security considerations. Roblox's built-in loadstring is disabled by default and is not available to LocalScripts. This guide is for development in experiences you own or are authorized to edit; it is not a guide to third-party executors.

## Safety and compatibility

- Only run code you have reviewed and understand.
- Treat code downloaded from the internet as untrusted until you have inspected it.
- Avoid loading code from links that can be changed by someone else without your knowledge.
- Do not put passwords, private tokens, API keys, or other secrets in scripts or public files.
- Some scripts may depend on a particular game, Roblox API behavior, or environment. Read each script's own notes before use.
- Back up your project before testing unfamiliar code.
