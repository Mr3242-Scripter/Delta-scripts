## About the collection

Some entries may be experimental, outdated, incomplete, or specific to a particular Roblox experience. A file's presence in this repository should not be interpreted as a guarantee that it is currently functional or supported.

## Reviewing source files

Before using or adapting any code, review the complete file and consider:

- **Purpose:** Identify what the script is intended to do.
- **Dependencies:** Check for required services, libraries, or runtime features.
- **Network activity:** Review any external URLs, downloaded code, or remote requests.
- **Permissions and effects:** Understand what the script can access or change.
- **Compatibility:** Check whether the code depends on a particular game, platform, or environment.

Treat unfamiliar code and externally hosted content as untrusted. Remote source files can change after they have been reviewed. Do not enter passwords, authentication tokens, API keys, or other private information into scripts.
