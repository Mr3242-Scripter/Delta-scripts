The contents can change over time. Individual scripts may be experimental, outdated, incomplete, or dependent on external services and libraries. Their presence in this repository does not imply that they are actively maintained or guaranteed to work.

## QuantumX Hub V2.1

QuantumX Hub V2.1 acts as a script browser and launcher for the repository's `Scripts` directory.

When executed in a compatible environment, it loads the available script entries into a Rayfield-based interface. Users can browse the listed entries and select a script to execute.

The scripts presented by the hub may be updated independently of the hub itself. Review the source of any selected script before running it.

## Source review and security

Review code before executing, modifying, or redistributing it. In particular:

- **Purpose:** Understand what the script is designed to do.
- **Dependencies:** Identify required libraries, services, and runtime features.
- **Remote content:** Check external URLs, downloaded source code, and network requests.
- **Permissions and effects:** Understand what the script can access, modify, or trigger.
- **Compatibility:** Confirm that the script is intended for the relevant Roblox experience and environment.

Treat unfamiliar code and externally hosted content as untrusted. Remote files can change after an initial review, so inspect the current source rather than relying on an older copy. Never provide scripts with passwords, authentication tokens, API keys, or other confidential information.
